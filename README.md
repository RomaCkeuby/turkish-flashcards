# Turkish Flashcards

Веб-приложение для персонального изучения турецких слов и словосочетаний через карточки и интервальные повторения. Работает локально; для тестирования с телефона доступен бесплатный запуск через интернет на своём ПК.

Приложение работает на `localhost`. Начальная SQLite-база содержит 250 базовых турецких слов и выражений, а для каждого слова созданы карточки TR → RU и RU → TR. После открытия перевода ответ `Верно` или `Неверно` сохраняется и определяет дату следующего показа.

Учебная очередь показывает сначала просроченные повторы, затем новые карточки. Дневного лимита новых карточек нет. С главной можно отдельно начать повторение или учить только новые слова. Главная страница и экран учёбы показывают статистику дня: сколько карточек повторить, сколько новых доступно, сколько ответов уже дано и какая точность.

В занятии работают быстрые клавиши: пробел открывает перевод, `1` отмечает неверный ответ, `2` — верный, `Ctrl/Cmd + Z` отменяет последнюю оценку. Отмена восстанавливает предыдущий интервал и статистику. Доступна только последняя оценка, включая ответы из других вкладок; повторная отмена или отмена после изменения прогресса не перезаписывает данные.

Переход в редактор и обратно сохраняет текущую карточку и открытый перевод. Редактор хранит черновик в текущей вкладке, сохраняет только изменённые поля и поддерживает `Ctrl/Cmd + S`. Статус, источники, история и предложения из локальных словарей отделены от основного сохранения.

Поиск по личной коллекции не отправляет запросы во внешние словари автоматически. Если слово не найдено, кнопка «Найти в интернете» запускает Викисловарь и Tatoeba. Кнопка «Из подборки» добавляет слова из уже сохранённых локальных данных.

На стороне ответа карточка также показывает короткий пример употребления на турецком языке и перевод примера на русский. Примеры берутся из открытых Turkish-Russian пар Tatoeba, источник отображается на карточке, а изучаемое слово в турецком примере выделяется жирным. Сейчас источниковые примеры найдены для 237 из 250 слов.

## Команды

```bash
pnpm install
pnpm typecheck
pnpm test
pnpm build
pnpm dev
pnpm --filter @turkish-flashcards/server updates:build
```

Команда `pnpm dev` запускает интерфейс на `http://127.0.0.1:5173` и локальный API на `http://127.0.0.1:3001`. База создаётся автоматически в `apps/server/storage/turkish-flashcards.db`.

Команда `updates:build` читает локально скачанный Kaikki/Wiktionary extract `apps/server/import-cache/tr-extract.jsonl.gz` и создаёт компактный пакет `apps/server/update-packages/current/cards.jsonl.gz` с `manifest.json` и SHA-256. Текущий пакет содержит 600 записей: 250 базовых и 350 новых записей с русским переводом из Kaikki/trwiktionary и примером из Tatoeba. Применение пакета доступно в настройках приложения: сначала показывается preview со списком конкретных изменений, затем обновление выполняется транзакцией с возможностью отката.

Карточки имеют архитектуру Base / Override: базовые данные приходят из локальной коллекции, Kaikki/Wiktionary и Tatoeba, а пользовательские исправления хранятся отдельно. Интерфейс всегда показывает пользовательский Override при его наличии, поэтому интернет-обновления не перезаписывают личные переводы, примеры, теги, категорию и статус карточки.

Новые личные карточки можно добавлять вручную на странице словаря. Для такой записи создаётся источник `Пользователь`, две учебные карточки и запись в истории изменений.

Обновления коллекции не изменяют и не отключают личные слова, в том числе при совпадении турецкого слова с записью пакета. Откат отменяет изменения конкретного обновления и сохраняет последующие личные добавления, пользовательские правки и учебный прогресс. При конфликте с более поздними изменениями базовых данных откат не выполняется. Повторное применение пакета восстанавливает отключённые откатом учебные карточки.

Начальная подборка добавляется только для отсутствующих записей и не перезаписывает сохранённые данные при перезапуске. Пользовательский список тегов заменяет исходные теги целиком; пустой список удаляет все теги. Пустые поля примера также сохраняются и скрывают исходный пример в обучении.

Команда `pnpm test` запускает регрессионные тесты обновления, отката, миграции и редактирования. `pnpm --filter @turkish-flashcards/server db:check` проверяет основные сценарии приложения. Обе проверки используют отдельные тестовые базы и временные пакеты, не меняя рабочую базу и пакеты обновления.

## Бесплатный доступ с телефона (Windows)

Сайт работает на вашем компьютере, а Cloudflare Quick Tunnel выдаёт временный HTTPS-адрес. Аккаунт Cloudflare, домен и платный хостинг не требуются. Компьютер должен быть включён, подключён к интернету и не находиться в спящем режиме. После нового запуска туннеля адрес меняется. Quick Tunnel предназначен для тестирования, без гарантии доступности: https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/.

1. Выполните `pnpm install`, затем `pnpm build`.
2. Скачайте официальный `cloudflared-windows-amd64.exe` со страницы https://github.com/cloudflare/cloudflared/releases/latest и сохраните как `.tools/cloudflared.exe` в проекте. На Windows проверьте действительную цифровую подпись Cloudflare перед запуском.
3. Выполните `pnpm personal:start`. Скрипт запускает сервер на `127.0.0.1:3002`, создаёт случайный пароль и выдаёт интернет-ссылку.
4. Откройте ссылку на телефоне. Браузер попросит логин и пароль: они записаны в `.personal/access.json` на вашем ПК. Пароль не попадает в интерфейс, логи и Git.
5. Чтобы остановить сервер и туннель, выполните `pnpm personal:stop`. Прогресс и пароль сохранятся.

Локальная и интернет-версия используют одну базу `apps/server/storage/turkish-flashcards.db`. Доступ к сайту и API защищён HTTP Basic через HTTPS туннеля. Публичный `/healthz` возвращает только `ok`. Открывать порты роутера не нужно. Для обновления работающей версии: `pnpm personal:stop`, `pnpm build`, `pnpm personal:start`.

`.personal/`, `.tools/`, SQLite-базы, `.env`, логи и временные файлы исключены из Git. При публикации кода на GitHub учебный прогресс и пароль остаются на компьютере. Публичность исходников не открывает доступ к личному сайту.

## Запуск на постоянном сервере

После `pnpm build` запустите `pnpm start`, задав переменные из `.env.example` в окружении процесса. Для `NODE_ENV=production` обязательны `APP_USERNAME`, пароль `APP_PASSWORD` от 16 символов и абсолютный `DATABASE_PATH` на постоянном диске. Сервер отдаёт интерфейс и `/api` на одном порту, поддерживает `HOST` и `PORT`. Укажите `IMPORT_PACKAGE_DIRECTORY` на постоянном диске для пакетов импорта. Файл `.env.example` — образец; автоматически он не загружается. При самостоятельном хостинге требуется HTTPS-прокси.
