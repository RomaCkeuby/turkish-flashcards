# Состояние реализации

Ветка: `codex/hybrid-offline-accounts`.

Начальная проверка 2 ноября 2026: `pnpm typecheck` — успешно; `pnpm test` — 37 серверных и 5 интерфейсных тестов успешно.

Рабочая копия до запуска содержала незакоммиченные изменения. Они сохранены; автоматический сброс, очистка и массовый коммит не выполняются.

## Первая волна

| Агент | Подэтап | Состояние |
| --- | --- | --- |
| `interface` | I1: гостевые экраны, режимы, статическая сборка | Завершено и интегрировано |
| `cards` | C1: публичная подборка и браузерная колода | Завершено и интегрировано |
| `remote_access` | R1: контракт и отдельный модуль авторизации | Завершено; подключение HTTP — следующий этап |

Общие типы: `apps/web/src/publicDeckTypes.ts`.

Принятые договорённости:

- Обычная локальная/серверная сборка сохраняет серверный режим по умолчанию.
- Статическая сборка (`VITE_STATIC_SITE=1`) начинает в гостевом режиме и использует маршрутизацию, совместимую с GitHub Pages; базовый путь задаётся `VITE_BASE_PATH`.
- Публичный пакет: `decks/manifest.json`, JSON-массив карточек в файле с контрольной суммой в имени.
- Гостевая колода: `createGuestDeck(entries, filters, random?)`; одна запись на каждую карточку выбранного направления за проход.
- Auth-модуль первой волны не подключается к рабочему серверу и не запускает миграции рабочей базы. Его приёмка выполняется на отдельной тестовой SQLite.

## Итоги приёмки первой волны

- `pnpm typecheck`: успешно.
- `pnpm test`: 54 серверных + 16 web-тестов, все успешно.
- `pnpm build`: успешно; обычная сборка в `apps/web/dist` сохраняет серверный режим.
- `pnpm build:static` с `VITE_BASE_PATH=/hybrid-test/`: успешно; отдельный каталог `apps/web/dist-static` исключён из Git.
- `pnpm decks:build`: 600 записей, воспроизводимая SHA-256; публичный JSON 484 817 байт.
- Проверка Playwright при ширине 390 px, через временный локальный preview, с блокированными `/api/**`: главная, обучение, оценка, отмена, поиск, карточка, настройки и перезагрузка прямой ссылки работают. Горизонтального переполнения на проверенных экранах нет. Это проверка браузера с мобильным размером окна, а не реального телефона.
- Browser smoke выявил несовместимость источников `local://curated-basic-v1` с загрузчиком; исправлено. Такие источники отображаются текстом. Добавлен регрессионный тест загрузки всего настоящего публичного пакета.
- Сборщик esbuild в песочнице не мог читать родительский каталог; сборки и временный preview повторены с разрешённым доступом. Это ограничение окружения проверки, а не ошибка приложения.
- Рабочая SQLite-база не мигрировалась, аккаунты в HTTP API не включались, действующий туннель не переключался. Git-коммиты, push и публикация не выполнялись.

Отчёт интерфейса: `agent-tasks/INTERFACE-I1-REPORT.md`. Контракт аккаунтов и матрица прав: `docs/hybrid-auth-api.md`.
